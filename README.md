# ☁️ Cloud Vault

A secure cloud-based file management system with AI-powered insights, enabling users to upload, manage, share, and analyze files efficiently.

---

## 🚀 Features

- 🔐 User Authentication & Authorization
- 📁 File Upload, Download & Management
- 🔗 Secure File Sharing System
- 🤖 AI-powered Insights
- 📊 File Analytics Dashboard

---

## 🛠 Tech Stack

**Frontend:**
- React.js / HTML / CSS / JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB

**Cloud & AI:**
- AWS S3
- AI Integration (Hugging Face / custom)
